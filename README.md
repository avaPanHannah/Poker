#Poker 遊戲
核心功能下注系統：玩家可自訂押注金額，系統將自動扣除總資金並即時更新介面顯示。  
動態交互：支援自動洗牌與發牌，玩家可透過點選圖片（翻轉牌面）來決定要更換的手牌。  
牌型判斷與結算：自動識別皇家同花順（250倍）、葫蘆（9倍）等牌型，並依賠率計算獎金回饋至總資金中。  
本專案具備直觀的視覺化介面與完整的獲勝邏輯，提供流暢的模擬賭場體驗。
